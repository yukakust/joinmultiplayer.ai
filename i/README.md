# i

A result that earned its dot.

The dot means **tested**, not **true**.

The person or team that made the original trace cannot independently place its
dot. Link the check or experiment and identify the independent verifier when a
human judgment is part of the result.

Keep the hypothesis ID. Name each result `HNNN-short-name.md`, link its idea and experiment, then
record:

```text
outcome: supports | challenges | inconclusive
confidence:
what changed:
next question:
```

Every result must point back to the question at the root of this laboratory.
The next question returns to [`hypotheses/`](../hypotheses/).
