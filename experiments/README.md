# experiments

Where an idea meets a baseline.

One experiment may test many hypotheses. Give it its own ID and name it
`ENNN-short-name/`:

Every experiment follows the complete public result contract in
[`METHOD.md`](../METHOD.md). At minimum, keep the question and complete prompt,
unedited outputs, exact model versions, date, settings, tools, context,
baseline, resource budget, ground truth, direct sources, evaluation method,
analysis, limitations, and reproduction instructions together.

Prefer a small test that can be repeated over a grand demo that cannot.
Keep code, inputs, outputs, and surprises together.
