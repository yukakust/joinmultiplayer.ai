## Public result contract

- **experiment ID:** E001, protocol E001-v0.3
- **source door and hypothesis:** D02, H027
- **stage:** locked three-seed mechanism pilot
- **question:** Can independently personalized towers return bounded compatible neural deltas that a source model composes into an answer unavailable to its base, fresh clones, or either tower alone?
- **complete prompt:** N/A. Tasks are deterministic `(specialty, key) × 2` records generated by `e001.data`; every exact test input and output is in the linked JSONL artifacts.
- **model:** repository commit `16205172c676d74aebe8817e8c008a57a7162f00`; custom PyTorch E001 modules; Python 3.14.4; PyTorch 2.13.0+cpu.
- **date and environment:** 2026-08-20; yukabox; AMD Ryzen AI 9 HX 470; 64 GB physical RAM; CPU execution with eight PyTorch threads.
- **tools and context:** no browsing, retrieval, external tools, or language-model API. Each pocket i receives only its specialty's complete private 64-bit fact table. Central heads receive only train-partition tasks.
- **locked settings:** [`configs/locked-pilot.json`](configs/locked-pilot.json), SHA-256 `80d832bf25025cbdb378b19b1170d97cbe3e2d58e4a1fdef3874a3a82491f1b3` for seed 17082201 before the seed override.
- **seeds:** 17082201, 17082202, 17082203.
- **ground truth:** synthetic deterministic private worlds generated by SHA-256; no external source applies. Each specialty has 44/9/11 key-disjoint train/validation/test keys. Each seed has 1,452 locked test tasks.
- **system under test:** `FinalLayers(z0 + Clip(Merge(delta_first, delta_second)))`, where `z0` is a frozen, order-aware source representation and each delta is `PersonalTower(h) − BaseTower(h)` projected through the fixed ABI.
- **baselines:** separately trained base-only, depth/interface-matched fresh clones with zero personalization, first-role only, second-role only, and a no-input class prior. Exact training access is recorded in every seed summary. Oracle memory is reported only as a ceiling.
- **resource budget:** per seed, 215,968 shared parameters, 879,680 personal trainable parameters, and 52,828 central/control trainable parameters; 240 expert steps, 360 central-head steps; about 21 seconds and 1.2 GiB peak RSS. The three-seed suite took 64.45 seconds.
- **evaluation:** micro and macro accuracy, lift over the strongest separately trained control, loss after removing a role, complete-backup recovery, fresh-delta tolerance, frozen-boundary assertions, key disjointness, and poisoned-partial invariance. No task-level IID confidence interval is claimed.
- **complete outputs:** [`suite-summary.json`](artifacts/20260820T075542Z-suite-3-seeds/suite-summary.json) and the three adjacent seed directories. They contain 4,356 unedited task records, predictions for every condition, routes, completion states, hashes, gates, timing, and limitations.

## Result

All three locked seeds passed every preconfigured gate.

- Personal Delta Towers: 100% micro and macro accuracy on every seed.
- Forced failure of every preferred expert: 100% on every seed; no partial payload entered the merger.
- Strongest trained control: 55.46% mean micro accuracy, range 54.27–56.06%.
- Collective lift: +44.54 percentage points mean, range +43.94–45.73.
- Macro lift: +44.37 percentage points mean, minimum +43.72.

This supports one narrow claim: explicitly supervised, ABI-compatible neural
deltas from two locally trained towers can be composed on unseen central keys,
and a second distinct specialist can replace an incomplete preferred
specialist without changing the answer.

## Limitations

- The ABI is deliberately one-hot and supervised; compatible latent language did not emerge.
- The synthetic task tests composition, not natural language, reasoning, mutable facts, routing discovery, WAN streaming, privacy, or malicious complete experts.
- Both specialists in a specialty learn the same fact table. This tests availability failover, not the benefit of semantic diversity.
- The fresh-clone control matches depth and interface, not executed FLOPs; E001 makes no efficiency claim.
- `PDT without z0` also scored 100%. The common base is present and order-aware, but this task does not require its knowledge.
- Tasks within a world reuse structured facts, so uncertainty is summarized across three worlds rather than with a misleading task-level IID interval.
- This is not an independent replication and does not place the dot on H027.
