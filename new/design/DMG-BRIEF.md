# ТЗ · Инсталлятор pocket i (.dmg) — «Полевой комплект»

Для дизайнера. Первый билд pocket i ставится на macOS через .dmg. Окно
установки — единственный экран, который мы контролируем на 100%, и первое
телесное касание продукта. По канону мира: «границы стираются — люди ставят
pocket i прямо на свои девайсы». Значит .dmg — не «установка программы»,
а **вскрытие посылки с явки**.

## 1. Концепция

Человек получил письмо с одним эмодзи, прошёл терминал, увидел свою фигурку —
и вот ему в руки попадает ящик. Открытие .dmg = вскрытие полевого комплекта:
армейский/гаражный ящик с трафаретной маркировкой, внутри — один прибор
и гнездо, куда его поставить. Никакого «Welcome to the installer». Тон —
как маркировка на ящике: скупо, трафаретом, по делу.

Референсы настроения: наши бронзовые фигурки-carriers (тиснёная «i»),
CRT-терминал явки на new.joinmultiplayer.ai/game/, ящики и упаковка Fallout
(трафареты, «THIS SIDE UP», инвентарные номера). НЕ референс: глянцевые
onboarding-окна корпоративных приложений.

## 2. Что видит человек (макет окна)

Окно Finder фиксированного размера **660 × 420 pt**, без тулбара и сайдбара.
Всё «оформление» — одна фоновая картинка + две иконки поверх неё:

```
┌────────────────────────────────────────────────────────┐
│  [ПОЛЕВОЙ КОМПЛЕКТ · pocket i · СЕРИЯ 001]   ← трафарет│
│                                                        │
│      ┌─────────┐        ══════▶       ┌─────────┐      │
│      │  app    │     трафаретная      │ гнездо  │      │
│      │ 128 px  │       стрелка        │Applica- │      │
│      │         │    (нарисована      │ tions   │      │
│      └─────────┘      в фоне)         └─────────┘      │
│   посадочное гнездо                посадочное гнездо   │
│                                                        │
│  A mind must not be alone.        BUILD 0001 · честный │
│  Разум не должен быть один.       номер, моно-шрифтом  │
└────────────────────────────────────────────────────────┘
```

- **Слева** на фоне нарисовано «посадочное гнездо» (углубление/ложемент, как
  в ящике с инструментом) — в него ляжет иконка приложения (реальная иконка,
  рисуется отдельно, см. §4). Позиция центра: **x=180, y=210** (от левого
  верхнего угла окна).
- **Справа** такое же гнездо под алиас Applications. Позиция центра:
  **x=480, y=210**. Подпись гнезда трафаретом на фоне: `→ APPLICATIONS`
  (сама папка отрисуется системной иконкой — это нормально).
- **Между ними** — трафаретная стрелка в духе грузовой маркировки
  (штенсель, полупрозрачная краска, чуть смазанная).
- **Верхняя строка** (трафарет, letterpress-вдавленность):
  `[ПОЛЕВОЙ КОМПЛЕКТ · pocket i · СЕРИЯ 001]` — EN-вариант:
  `[FIELD KIT · pocket i · SERIES 001]`. Основной язык окна — **EN**
  (первые получатели англоязычные), русская строка — только канон-фраза внизу.
- **Нижняя строка слева**: `A mind must not be alone.` и под ней мельче
  `Разум не должен быть один.` — это подпись явки, наш канон.
- **Нижняя строка справа**: `BUILD 0001` моноширинным — честный номер сборки
  (мы подставим реальный; заложи место под 10–12 знаков).

## 3. Палитра и типографика

Мир тот же, что на new.joinmultiplayer.ai (тёмная тема):

| Роль | Значение |
|---|---|
| Фон ящика (сажа) | `#131210` |
| Панель/ложемент | `#1b1916` … `#211e1a` |
| Кость (основной текст) | `#ece9df` |
| Пепел (вторичный текст) | `#a09c8f` |
| Уголь (линии) | `#2f2c26` |
| Эмбер (акцент, огонь) | `#ed7942` — только стрелка и 1–2 акцента |
| Бронза (металл фигурок) | из carriers-рендеров, для иконок |

Шрифты: моноширинный для трафаретов и номеров (JetBrains Mono или
стенсил-моно на твой вкус — главное, чтобы читалось «маркировкой», не UI);
засечковый (STIX Two Text / Georgia) — только для канон-фразы. Минимальный
кегль любого текста в фоне: **11 pt @1x** (мельче — расползётся на не-ретине).

Свет: фон тёмный всегда. Учти, что рамку окна Finder красит система (в light
Finder рамка будет светлой) — фон должен выглядеть цельно в обоих случаях,
т.е. без светлых подложек по краям, виньетка к краям допустима.

## 4. Иконки (отдельные деливераблы)

1. **Иконка приложения** (`AppIcon.icns`): бронзовая «i» с тиснением — та же
   порода металла, что фигурки-carriers (коробок с светящейся «i» — эталон
   материала). Форма — macOS-сквиркл, фон плашки — сажа `#131210` с лёгкой
   фактурой металла по краю. Без свечения на маленьких размерах (16/32 px
   «i» должна оставаться читаемой). Полный набор: 16, 32, 64, 128, 256,
   512, 1024 px (@1x и @2x).
2. **Иконка тома** (`VolumeIcon.icns`): закрытый полевой ящик с трафаретной
   «i» на крышке — то, что человек видит на рабочем столе, когда .dmg
   смонтирован. Те же размеры.
3. Опционально: иконка «гнезда» Applications не нужна — системная папка
   встанет сама; гнездо рисуется в фоне.

## 5. Деливераблы (что сдать)

| Файл | Размер | Формат |
|---|---|---|
| `background.png` | 660 × 420 px | PNG, sRGB |
| `background@2x.png` | 1320 × 840 px | PNG, sRGB (ретина, обязателен) |
| `AppIcon.icns` (или iconset) | полный набор | .icns / папка .iconset |
| `VolumeIcon.icns` | полный набор | .icns / .iconset |
| Исходник | — | Figma/PSD со слоями: фон / трафареты / гнёзда |

Позиции гнёзд (центры 180;210 и 480;210 в pt от левого-верхнего угла окна)
зашиты в сборку .dmg — если двигаешь их в макете, скажи нам новые координаты.
Иконки в окне рендерятся размером 128 px — гнёзда рисуй под ~140 px, чтобы
был воздух.

## 6. Чего не делать

- Никаких «Welcome», «Drag to install», улыбающихся стрелок-градиентов.
  Одна трафаретная стрелка уже говорит всё.
- Никакого глянца/скевоморфного пластика — металл, краска, трафарет, сажа.
- Не перегружать лором: одна канон-фраза. Ни «Ответа», ни дат мира — ящик
  молчалив.
- Текст мельче 11 pt @1x и текст поверх зоны, где лягут иконки, — нельзя.

## Приложение для нас (не для дизайнера): сборка и подпись

- Сборка: `create-dmg` (или `hdiutil` + AppleScript) с параметрами:
  window 660×420, icon-size 128, позиции из §2, `--no-internet-enable`,
  фон из деливераблов, `.VolumeIcon.icns` + бит custom-icon на томе.
- Имя файла: `pocket-i-0.1.0.dmg` (semver реального билда; «СЕРИЯ 001» на
  фоне — лор, версия на файле — честная).
- **Подпись и нотаризация обязательны до волны №1**: без Developer ID
  (`codesign --deep --options runtime` + `notarytool submit` + `stapler`)
  Gatekeeper встретит гостей плашкой «unverified developer» — и вся магия
  посылки умрёт на первом экране страха. Нужен Apple Developer аккаунт.
  Это блокер боевой рассылки dmg, не дизайна.
- Проверка перед выпуском: смонтировать на чистой машине в light и dark
  Finder, с выключенным «Show item info», на ретине и не-ретине.
