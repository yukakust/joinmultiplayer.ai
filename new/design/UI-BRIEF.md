# UI-ТЗ · Дизайн-кит игры joinmultiplayer.ai

Версия 1.0 · 29.08.2026 · для дизайнера. Живая версия, поверх которой рисуем:
**https://new.joinmultiplayer.ai** (страницы: `/journey/` тропа, `/play/` вход,
`/workbench/` верстак, `/map/` живая карта). Всё, что описано ниже, уже
работает кодом — задача дизайнера не придумать интерфейс, а **поднять качество
рисунка**: иконки, фигурки, статуэтки, чертёж, композиция выносок.

---

## 0. Что это и как читать ТЗ

Сайт — открытая научная лаборатория, поданная как игра-экспедиция:
- **Тропа** (`/journey/`) — история экспериментов как карта настолки: точки-миссии,
  тупики, статуэтки-достижения.
- **Фигурки** — игроки; каждый выбирает «носителя огня» (спичка, коробок…) и
  «зажигается», сделав первый ход.
- **Верстак** (`/workbench/`) — pocket i как разобранная буква **ı**: девять
  гнёзд-деталей, в каждом «предмет» с настоящими измеренными числами; сообщество
  «куёт» предметы лучше.

Два железных закона проекта, которые дизайн обязан уважать:

1. **Ни одной фейковой цифры.** Все числа в макетах — из таблицы в §7. Нельзя
   рисовать выдуманные статы, проценты, рейтинги.
2. **Закон восьмилетнего»: публичный слой должен читаться с первого раза.
   Если элемент требует легенды — элемент нарисован неправильно (подписи живут
   на самих объектах).

Стилевая рамка: **монохромный line-art** «бумага + чернила + один янтарный
акцент», настроение — патентный чертёж / лабораторный журнал / экспедиционная
карта. Никакого глянца, градиентных кнопок, эмодзи, 3D.

## 1. Дизайн-токены

### 1.1 Палитра (обе темы обязательны)

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `paper` | `#F4F1E8` | `#11110F` | фон |
| `ink` | `#15140F` | `#EEECE4` | основной штрих/текст |
| `muted` | `#716E64` | `#99968D` | вторичный текст, тихие линии |
| `line` | `rgba(21,20,15,.18)` | `rgba(238,236,228,.2)` | разделители |
| `ember` | `#B64F20` | `#ED7942` | ЕДИНСТВЕННЫЙ акцент: огонь, внимание, «сейчас» |
| `rust` | `#C0523A` | `#C0523A` | семантика «сломано» (только статус, не акцент) |

Правило: акцентом может быть только `ember`. `rust` — исключительно статус
поломки. Никаких новых цветов. Каждый макет сдаётся в обеих темах.

### 1.2 Типографика

- **UI/текст:** системный моноширинный стек (`ui-monospace, SFMono-Regular,
  Menlo, Consolas`). Дизайнить можно в SF Mono/JetBrains Mono — мы сведём.
- **Знак «i» и заголовки-манифесты:** Georgia / Times-класс серифа, курсивная
  строчная «i» — фирменный знак (см. лого, компас, точку силы).
- Кегли (desktop): body 17/1.66; подписи-«шильдики» 10–12 UPPERCASE с
  трекингом 0.1–0.18em; микроподписи на чертеже 8.5–9.5.

### 1.3 Штрих (line-art)

- Базовый вес **1.7** (иконки, фигурки, статуэтки, чертёж), тонкий **1–1.2**
  (лидеры, соединители), жирный **2.4–3** (выделение/статус «сломано»).
- Скругления: `round` cap/join. Углы контейнеров: rx 6–8.
- Заливок почти нет: только `paper`-плашки под слэбами и точечные
  `ember`-заливки (головка спички, пламя, глаз змея).

### 1.4 Язык статусов (единый по всему сайту)

| Статус | Рамка/линия | Где встречается |
|---|---|---|
| заморожено (эталон) | сплошная `muted` | детали-эталоны, шасси |
| пройдено | сплошная `ember` | капсула, приёмка |
| с оговоркой | сплошная `ink`, dash 7-3 | резак, судьи, обучение |
| **сломано** | сплошная `rust`, вес 2.4 + мотив трещины | сборщик |
| открыто/пусто | dash 3-4 `muted`, без заливки | роутер, пустой постамент, будущее |
| происходит сейчас | `ember` + мягкий пульс | точка «вы здесь», зов |

Дизайнеру: сейчас на верстаке три вида пунктира соседствуют и рябят — нужно
развести статусы так, чтобы они различались **с одного взгляда и без легенды**
(вес, ритм штриха, наличие трещины/замочка — на ваш вкус, в рамках таблицы).

### 1.5 Движение

Только со смыслом: отрисовка тропы при загрузке, вспышка «сокета», пульс
«сейчас», покачивание флага ±3px. Ничего декоративного, всё отключается по
`prefers-reduced-motion`. Хронометраж: micro 150–300ms, событие 600–800ms.

## 2. Фигурки игроков (8 шт + пустой слот)

**Смысл:** фигурка = игрок, как фишки в Монополии. Закон набора: каждая —
**носитель огня**. Два состояния: `unlit` (контур, огня нет) и `lit`
(появляется огонь: слой `flame`, цвет `ember`).

**Формат:** viewBox **40×48**, штрих 1.7, один слой `figure` (ink/currentColor)
+ один слой `flame` (ember). Обязана читаться в **18px** (отряд на тропе) и
жить в 26 / 44 / 72px (полоса на карте / галерея / ритуал).

| id | Имя | Образ | Замечания к рисунку |
|---|---|---|---|
| `match` | Спичка | палочка + головка | огонь — капля над головкой; дефолтная фигурка, самая узнаваемая |
| `matchbox` | Коробок | коробок с выдвижным лотком, спичка сверху | сейчас похож на кирпич — дать характер (лоток, тёрка) |
| `lighter` | Зажигалка | зиппо с открытой крышкой, колёсико | огонь из горловины |
| `flint` | Кремень | камень + кресало-дуга | огонь = искра-звёздочка между ними |
| `candle` | Свеча | свеча с потёком, фитиль | огонь — классическая капля |
| `lantern` | Фонарь | керосинка/штормовой: корпус, ручка-дуга, стекло | огонь внутри стекла + идея «света наружу» |
| `lens` | Лупа | линза с ручкой 45° | lit: сфокусированный конус лучей + точка возгорания под линзой |
| `sparkler` | Бенгальский огонь | палочка | unlit — просто палочка (это шутка набора), lit — звёздный взрыв искр + разлетающиеся точки |
| `empty` | Пустой слот | пунктирный обелиск-силуэт | для полки/слотов «ещё не случилось» |

Приоритет: у всех восьми должен быть **общий почерк** (вес, пропорции головы
огня, посадка на базовую линию), сейчас они разнобойные.

## 3. Статуэтки достижений (12 шт, набор растёт)

**Смысл:** памятники моментам лаборатории, стоят на тропе и на «полке».
**Формат:** viewBox **40×46**; постамент из двух ступеней (общий для всех);
фигура line-art + не больше одного `ember`-акцента. Размеры жизни: 21 / 45 /
66px. Анимация «получения» — обводка штриха (stroke draw-on), поэтому контуры
должны быть чистыми путями без каши мелких сегментов.

Список: Первая спичка · Две башни · Теплица роя (купол с точками) · Рой на
столе (телефон+ноут+сервер) · **Разбитая колонна** (гордость: опубликованный
провал) · Пойманный разворот (стрелка, развернувшаяся назад) · Возврат из
тупика (U-turn) · Откалиброванные весы · Панель Луны (полумесяц) ·
Запечатанная капсула (ампула с печатью) · Открытая коробка (Джуманджи) ·
Пустой постамент (пунктир).

## 4. Тропа `/journey/` («Путь лаборатории»)

Экспедиционная карта: вертикальная извилистая линия времени с боковыми
ответвлениями. Референсы жанра: альпинистские топо, карты Толкина, Camino.

Элементы (все уже в коде, нужен рисунок/полировка):

- **Линия пути:** пройденное — сплошные чернила (рисуется при загрузке);
  будущее — dash; ответвление-тупик — тоньше; **возврат** — ember-пунктир со
  стрелкой. Есть лёгкая «карандашная» дрожь (feTurbulence) — сохранить характер.
- **Узлы** (6 состояний): пройдено (заливка ink) · с оговоркой (полузаливка) ·
  тупик (× в кружке, rust) · сейчас (ember, пульс) · скрыто (? в пунктирном
  кружке) · старт. Подпись узла: `КОД` + короткое имя, слева/справа от линии.
- **Медали:** мини-статуэтка (21px) над узлом-вехой.
- **Акты:** горизонтальный dash-разделитель + шильдик «АКТ IV · Сигнал в рое».
- **Картуш** (титульная рамка карты): двойная рамка, «Путь лаборатории ·
  июнь–август 2026 · зажжено спичкой M0001». Можно добавить лёгкие уголки.
- **Компас:** роза, где вместо севера — курсивная **i** (ember-стрелка). Есть,
  можно сделать выразительнее.
- **Край карты:** пунктирная зона + line-art **змей** с ember-глазом + подпись
  «здесь карта кончается».
- **«Мы здесь»:** ember-вымпел на мачте (float ±3px) + **отряд**: фигурки всех
  зажжённых игроков кучкой у флага (18px, перекрытие -7px, ховер приподнимает).
- **Инспектор записи** (правая карточка / мобильный bottom-sheet): кикер
  `КОД · дата` → заголовок → рассказ → плашка «чего это не доказывает»
  (ember-кайма) → карточка статуэтки → кнопки-ссылки.
- Фон тропы: бумажное зерно (шум ~5% opacity) — сохранить.

## 5. Верстак `/workbench/` — главный объект этого ТЗ

Концепт: **pocket i = разобранная буква ı** (патентный взрыв-чертёж), а над
штамбом парит **точка** — в ней «СИЛА СБОРКИ 3/18». Точка над i «не заработана»:
рамка пунктиром. Когда сборка победит централизованный контекст — точка
«загорается» (ember, сплошная) — это будущий главный праздник интерфейса,
нарисовать оба состояния.

### 5.1 Анатомия чертежа

- **Точка силы:** круг r≈36; внутри крупно `3/18`, под ним шильдик. Состояния:
  unlit (dash, muted) / lit (solid, ember, лёгкое свечение).
- **Штамб:** 9 слэбов-гнёзд шириной ~128, разнесённых по вертикали; между ними
  короткие dash-соединители (exploded view). Внизу подпись-шасси:
  «chassis · Qwen3-0.6B · frozen».
- **Слэб гнезда:** рамка-статус (§1.4) + номер в кружке на левом ребре +
  иконка детали по центру. Слэб «сборщик» крупнее остальных (иерархия боли).
- **Выноски:** пунктирный лидер к подписи (имя жирным + рекорд muted).
  **Известная болячка:** сейчас подписи обрезаются и наезжают на слэбы —
  задать колонкам выносок гарантированную ширину, разрешить 2 строки рекорда,
  лидер не должен пересекать текст (см. скрин в §8).
- **Иконки деталей (9):** страницы (миры) · гребёнка-резак · лупа-искатель ·
  капсула-пилюля · воронка-приёмка с галочкой · вилка-роутер · шестерня-сердце
  с **трещиной** (сборщик, rust) · весы-судьи · вилка-адаптер (обучение).
  Сейчас это грубые заготовки — перерисовать в едином весе с фигурками.
  Требование: каждая читается в 22px.

### 5.2 Карточка предмета (инспектор)

Анатомия ARPG-тултипа, порядок жёсткий: `ГНЕЗДО N · СТАТУС-чип` → **имя
предмета** («Модульный harness v0.1 · разбит») → что делает (2–3 строки) →
`ИЗМЕРЕННЫЕ СТАТЫ` (моно-таблица key·value) → `ЗАМОРОЖЕНО — НЕ ТРОГАТЬ`
(плашка) → `ВЫКОВАТЬ ЛУЧШЕ` (dash-рамка: вызов, две дорожки «точнее/дешевле»,
кнопки «скопировать задание для ИИ» и «принести результат») → подвал
`ПРОИСХОЖДЕНИЕ · держатель: [фигурка] M0001 · ссылки`.

### 5.3 Момент сокета (задизайнить наперёд)

Когда чужой предмет проходит независимый перепрогон и встаёт в гнездо:
вспышка рамки (0.3s) → числа карточки пересчитываются каунт-апом → у гнезда
появляется фигурка нового держателя. Нужны кадры/спека этого момента — он
должен ощущаться наградой без фейерверка (сдержанный «клик» ювелирной работы).

## 6. Остальные игровые элементы

- **Коробка Джуманджи** (первый вход на `/play/`): тёмная сцена (в обеих темах
  тёмная — это сознательное исключение), line-art коробка с ember-«i» на
  крышке, пульсирующие кольца-«барабаны», «Слышишь? Игра нашла тебя»,
  одна ember-кнопка. Можно сделать коробку вкуснее (объём, клапаны, тень).
- **Зов «Игра зовёт»:** строка с пульс-точкой: `ИГРА ЗОВЁТ · Q0001 · вопрос
  открыт уже N дней — ход ещё ничей →`. Единственный пульс на странице.
- **Полоса «Спички за столом»** (`/map/`): чипы: фигурка 26px + M-номер + имя.
- **Ритуал зажигания** (страница статуса): контурная фигурка → зажжённая с
  янтарным свечением + блок «ЗАЖГИ СЛЕДУЮЩЕГО» с личной ссылкой.
- **Morrow** (лицо-проводник из спичечных головок) — существующий персонаж,
  в этом ТЗ не трогаем (отдельная итерация).

## 8. Известные болячки текущей версии (чинить в первую очередь)

1. Выноски верстака обрезаются («9/», «24/2», «relevanc») и наезжают на слэбы.
2. Три вида пунктира рядом (оговорка/открыто/лидеры) — рябь; развести ритмы.
3. Иконки деталей и часть фигурок разнобойные по весу и наивные по рисунку.
4. Подпись «ASSEMBLY POWER» касается кольца точки.
5. Иерархия: серые рамки почти равнозначны — сломанное гнездо должно кричать
   заметно громче остального (сейчас кричит вполголоса).
6. Скрин текущего состояния приложит Юка (или снять с live).

## 9. Поставка и приёмка

- **Figma-структура:** страницы `Tokens` / `Pieces` / `Statues` / `Trail` /
  `Workbench` / `Scenes` (+ light/dark варианты фреймов).
- **Экспорт иконок/фигурок/статуэток:** чистый SVG, только контуры
  (stroke, без expand), без растров и эффектов; слои с именами
  `figure` / `flame` / `accent` — мы вешаем классы и `currentColor` в коде,
  поэтому цвет в файле не важен, важна структура слоёв.
- Артборды: фигурки 40×48, статуэтки 40×46, иконки деталей 40×40,
  экраны 1280×… и 390×… (моб).
- **Приёмка:** элемент читается на минимальном размере из своей секции; работает
  в обеих темах; статусы различимы без легенды; ни одной выдуманной цифры;
  анимации описаны кадрами или прототипом.

Вопросы и правки — Юка (M0001). Интеграцию в код делает лаборатория.
