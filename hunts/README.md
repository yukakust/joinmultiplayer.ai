# hunts

A hunt is a public, time-bounded search opened by a door.

It turns a question into a shared mission before a formal experiment begins:

```text
door → hunt → journal → ı → experiment → i
```

Each hunt defines:

```text
mission:
roles:
evidence:
stop conditions:
outcomes:
```

A hunt does not begin with a verdict. It ends with a traceable record of what
was found, what remains missing, and which hypothesis should be tested next.
