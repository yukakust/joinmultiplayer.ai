Сначала собираем одну понятную desktop‑апку для macOS, Windows и Linux. Она читает только разрешённую локальную библиотеку, спрашивает другие pocket i и показывает человеку каждую отправленную частицу знания.

ОДИН КОД — ТРИ ПАКЕТА

Tauri показывает окно приложения. Один Python core выполняет harness. Нативный llama.cpp запускает выбранные модели. macOS получает .dmg, Windows — .exe/.msi, Linux — .AppImage. Модели скачиваются после установки; локальный UI не открывает отдельный публичный сервер.

Путь до MVP

1

Один core

2

Локальная библиотека

Лучший ответ отдельно; другие обоснованные версии не теряются.

Понятный UI

Установка модели, вопрос, разрешение и весь путь ответа.

7

Три сборки

macOS, Windows, Linux и один свежий тест на реальных машинах.

Не в этом MVP

Телефон, автономная отправка без подтверждения, обучение личных весов, произвольные папки и многоязычные обещания. Мы вернём их как отдельные модули после работающей desktop‑цепочки.

CHECKPOINT 1A · КАРКАС CORE ПРОШЁЛ 6/6 ТЕСТОВ

Один переносимый core теперь фиксирует порядок: вопрос → чаты → доказательства → точная цитата → секреты → разрешение владельца → две полки → ответ. Это ещё не интегрированный продукт: реальные модели, библиотеки, сеть, UI и установщики пока не подключены.

CHECKPOINT 2A · ЛОКАЛЬНАЯ БИБЛИОТЕКА ПОДКЛЮЧЕНА

Строгие адаптеры прошли 10/10 тестов. На настоящей yukabox модуль нашёл 58 разговоров Codex и 2 907 видимых сообщений, не публикуя текст, пути или ID. Реальные macOS и Windows ещё не проверены.

CHECKPOINT 3A · WHOLE-CHAT ROUTING ПОДКЛЮЧЁН

На одном настоящем вопросе ожидаемый разговор стал №1 среди 58. Готовый индекс отвечает за 0,20 секунды, но первое построение заняло неприемлемые 318 секунд. Следующая обязательная инженерная часть — постоянный incremental cache.
