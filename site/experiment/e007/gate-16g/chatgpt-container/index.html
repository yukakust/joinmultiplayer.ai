Берём тот же один бинарный файл. Пробуем только стандартные decoder’ы macOS. Если формат знакомый, оставляем максимум двадцать видимых сообщений. Остальные 85 файлов не открываем.

Готово к локальному запуску. На сайт попадут только название decoder’а, структура и количество сообщений. Байты и текст останутся на MacBook.
curl -fsS https://joinmultiplayer.ai/experiments/E007/local-conversation-adapters-v0.5.py \
  -o "$HOME/.local/bin/pocket-i-conversations" && \
chmod 700 "$HOME/.local/bin/pocket-i-conversations" && \
python3 "$HOME/.local/bin/pocket-i-conversations" decode-one-chatgpt \
  --output "$HOME/.cache/joinmultiplayer/e007-gate16g2/chatgpt-one-private.json"
